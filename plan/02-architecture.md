# 02. 構成(トポロジ・ネットワーク設計・IP アドレス計画)

## トポロジ

物理(仮想)配線は全演習を通して固定し、演習ごとに VyOS の設定だけを差し替える。

```
                  AS65001            AS65000 (ISP役)           AS65002
+---------+      +------+           +------+           +------+      +---------+
| client1 |------|  r1  |-----------|  r2  |-----------|  r3  |------| client2 |
+---------+      +------+           +------+           +------+      +---------+
      lan-a              wan-a               wan-b              lan-b
  192.168.10.0/24    10.0.12.0/30        10.0.23.0/30      192.168.20.0/24

                 ~~~~~~~~~~~ VPN (WireGuard / IPsec) ~~~~~~~~~~~
                 r1 ====================================== r3
                        (r2 をインターネットに見立てて越える)

mgmt: 172.16.99.0/24(libvirt NAT)
  └─ 全 5 VM の eth0 が接続。ホストからの SSH・設定投入・パッケージ取得用。
     演習対象のトラフィックは流さない(out-of-band 管理専用)。
```

- **r2 が「インターネット / ISP」役**。BGP 演習では中継 AS、VPN 演習では
  「LAN のプレフィックスを知らない中間網」として振る舞う
- ルータ 3 台が最小構成で全テーマをカバーできる根拠:
  - DHCP: r1 / r3 が各 LAN に配布
  - OSPF: 3 台 1 エリアで隣接・経路伝搬・コスト操作を観察できる
  - BGP: 3 AS の直列で eBGP ピアリング・経路広告・AS パスを観察できる
  - VPN: 中間に「LAN を知らない」r2 がいることでトンネルの意義が成立する
  - Firewall: r1 のゾーンベース FW で LAN/WAN 間を制御

## libvirt ネットワーク設計

| ネットワーク名 | モード | アドレス | 用途 |
|---|---|---|---|
| labnet-mgmt | NAT(forward mode=nat) | 172.16.99.0/24 | 管理用。ホスト側 GW 172.16.99.1。libvirt の DHCP は無効化し全 VM 静的 IP |
| labnet-lan-a | isolated | 192.168.10.0/24 | サイト A の LAN(ホスト側 IP なし) |
| labnet-lan-b | isolated | 192.168.20.0/24 | サイト B の LAN(ホスト側 IP なし) |
| labnet-wan-a | isolated | 10.0.12.0/30 | r1–r2 間 P2P リンク |
| labnet-wan-b | isolated | 10.0.23.0/30 | r2–r3 間 P2P リンク |

- isolated ネットワークはホストに IP を持たせず、DHCP も無効。純粋な「仮想スイッチ」として使う
  (DHCP 演習で libvirt の dnsmasq が混ざらないようにするため必須)
- 既存の libvirt `default` ネットワークとは衝突しないよう、すべて `labnet-` プレフィックスを付ける

### 演習ネットワーク

| VM | インターフェース | 接続先 | IP |
|---|---|---|---|
| r1 | eth0 | labnet-mgmt | 172.16.99.11/24 |
| r1 | eth1 | labnet-lan-a | 192.168.10.1/24 |
| r1 | eth2 | labnet-wan-a | 10.0.12.1/30 |
| r2 | eth0 | labnet-mgmt | 172.16.99.12/24 |
| r2 | eth1 | labnet-wan-a | 10.0.12.2/30 |
| r2 | eth2 | labnet-wan-b | 10.0.23.1/30 |
| r3 | eth0 | labnet-mgmt | 172.16.99.13/24 |
| r3 | eth1 | labnet-lan-b | 192.168.20.1/24 |
| r3 | eth2 | labnet-wan-b | 10.0.23.2/30 |
| client1 | eth0 | labnet-mgmt | 172.16.99.21/24 |
| client1 | eth1 | labnet-lan-a | DHCP(演習前は静的 192.168.10.100/24) |
| client2 | eth0 | labnet-mgmt | 172.16.99.22/24 |
| client2 | eth1 | labnet-lan-b | DHCP(演習前は静的 192.168.20.100/24) |

- VM 定義時の NIC の並び順を「mgmt → LAN/WAN」で統一し、ゲスト内の eth 番号と対応させる
